⌚ Index Notes

Voice notes dictated on your Pebble are written to your own account's recordings collection, where the Pebble mobile app picks them up into the Index feed. Your credentials are stored only on your phone.

The public client key of the Pebble app's Firebase project (see the project README for how to find it).
